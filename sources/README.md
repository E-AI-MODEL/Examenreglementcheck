# Bronbestanden

Leidend zijn `registry.json`, `fragments.json`, `jurisprudence.normalized.json` en `../rules/candidates.json`. De bronlaag is rechtstreeks overgenomen uit bronnenpakket 0.2.

`registry.yaml` is een gegenereerde compatibiliteitskopie. `jurisprudence.seed.json` is een gegenereerde kopie van de genormaliseerde zaken. De ongewijzigde oorspronkelijke v1-bronbestanden staan onder `../archive/v1/sources/`.

`content/` bevat de relevante teksten of bronbeschrijvingen. `originals/` bevat de in bronnenpakket 0.2 opgehaalde overheidsbestanden. De bronregistratie bevat 40 records, waarvan 38 destijds zijn opgehaald. Twee volledige LKC-adviezen bleven niet bereikbaar.

Alle `production_approved`-velden staan op `false`. Een opgehaalde bron is niet automatisch juridisch goedgekeurd.
