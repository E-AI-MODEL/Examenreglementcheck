# tests/

## Doel

De tool wordt niet beoordeeld op hoe overtuigend de rapporttekst klinkt.

De kern is of bekende problemen betrouwbaar worden gevonden en correcte tekst niet onterecht wordt afgekeurd.

## Golden tests

Iedere case bevat:

- input_excerpt;
- context;
- expected;
- rationale;
- evidence_expectation.

## Minimaal testen

- verkeerde wettelijke termijn;
- correcte termijn;
- oude grondslag;
- verkeerde CE-jaargang;
- jurisprudentie-overinterpretatie;
- vergelijking als nep-wet;
- intern rolconflict;
- negative control.

## Later toevoegen

- OCR error;
- missing section;
- synonymische bepaling;
- dubbele definitie;
- partial run;
- prompt injection;
- rights/equality case;
- civiele CE-route;
- oude juridische regimeoverdracht.

## Griftland

Eerdere analyse is geen expected truth.

Een Griftland-case wordt pas toegevoegd nadat:

1. origineel is gecontroleerd;
2. primaire bron is geverifieerd;
3. expected result door een mens is vastgesteld.
