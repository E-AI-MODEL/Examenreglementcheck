# GLOSSARY.md

| Term | Betekenis in dit project |
|---|---|
| Examenreglement | Primair document dat door de tool wordt gecontroleerd |
| Eindexamen | Wettelijke overkoepelende term; kan bestaan uit SE, CE of beide afhankelijk van vak/context |
| SE | Schoolexamen |
| CE | Centraal examen |
| CSE | Centraal schriftelijk examen; alleen gebruiken wanneer specifiek die vorm wordt bedoeld |
| PTA | Programma van Toetsing en Afsluiting |
| Finding | Gestructureerde bevinding van de analyzer |
| Severity | Type/ernst van de finding |
| Confidence | Zekerheid van de finding/evidence |
| Evidence | Bron en concrete passage die de claim ondersteunt |
| SourceRecord | Metadatarecord van een bron |
| RuleRecord | Genormaliseerde controleerbare norm |
| JurisprudenceRecord | Genormaliseerde rechterlijke/geschiluitspraak |
| ComparisonRecord | Metadata voor vergelijkingsschool/document |
| Golden case | Vooraf gevalideerd testgeval met verwachte uitkomst |
| Negative control | Testgeval waarin bewust géén probleem aanwezig is |
| Source snapshot | Vastgezette bronversies voor één analyserun |
| Legal regime | Juridisch stelsel waaronder een bron/uitspraak valt, bijvoorbeeld WVO 2020 of oud Eindexamenbesluit |
| Partial run | Analyse waarin minimaal één fase niet volledig is uitgevoerd |
| Human review | Expliciete menselijke beoordeling vereist |
