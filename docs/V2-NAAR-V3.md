# Van v2 naar v3

V2 was een bronpakket en reviewprototype. V3 voegt de eerste echte runtime toe.

**Nieuw gebouwd:** echte PDF/DOCX-extractie, documentcheck, vijf deterministische registers, interne consistentie, deterministische bronkandidaten, echte runstatus, A-I-faseweergave en een expliciete no-AI/AI-modusgrens.

**Bewust niet gebouwd:** modelcalls, promptmodules, OCR, volledige juridische completeness, SE/CE-analyzer, jurisprudentie-analyzer, vergelijking, tegenlezing en een semantische evidence-validator.

De centrale ontwerpkeuze is aangescherpt: **zonder AI is een volwaardige basisrun mogelijk**. AI wordt later een optionele verdieping en mag de bronpoort niet omzeilen.
